# История изменений

## 3.1 — октябрь 2026

**Плагины** — вернулись из Ngram 2.x, теперь на настоящих классах Telegram

- Расширения на Python 3.11 с именами SDK, как в exteraGram: команды, перехват отправки, хуки запросов и обновлений, пункты меню, собственные настройки.
- Установка из файла, из сообщения в чате и из трёх встроенных примеров; согласие перед установкой.
- Страховка: самоотключение плагина после 8 ошибок подряд, безопасный режим, журнал.

**Чаты** — новый раздел настроек

- Секунды во времени сообщений, точные числа вместо «12,3K», размер стикеров.
- Двойное нажатие на сообщение: реакция, ответ, изменить, скопировать, в Избранное, подробности или ничего.
- Вопрос перед отправкой стикера, GIF и перед звонком; «сначала прослушать» для голосовых.
- Отключаемый переход к следующему каналу потягиванием; скрытие клавиатуры при прокрутке.
- Меню сообщения: «В Избранное», «Повторить», «Копировать фото», «Сохранить стикер как картинку», «Подробности».
- Меню чата → Ngram: шаблоны с подстановками, переход к началу чата, статистика, экспорт переписки в текст, веб-страницу или JSON.
- «Сведения» в меню профиля.
- «Скрывать мой номер» и запрет снимков экрана.

**Оформление**

- Цветной оттенок стекла.
- Наборы стекла: пять готовых и свои.
- Шесть значков приложения Ngram вместо значков Telegram.
- Свой заголовок главного экрана; ряд историй можно убрать.

**Ассистент**

- Несколько разговоров: список, переименование, удаление.
- Картинки: что на фото, текст с фото, вопрос о фото.
- Расшифровка голосовых и видеосообщений через провайдера (модель для речи в настройках провайдера).
- В секретных чатах и чатах с запретом копирования ассистент не предлагается.

**Данные**

- Копия настроек Ngram в файл и восстановление из файла (без ключей API).
- Диагностика: отчёт и последний сбой.

**Прочее**

- Приложение стало больше примерно на 18 МБ: в него встроен Python.
- Номер сборки включает версию Ngram, поэтому 3.1 ставится поверх 3.0.

## 3.0 — октябрь 2026

Ngram переехал на исходный код Telegram для Android 12.10.6. Предыдущие версии (1.x–2.x) были отдельным приложением на TDLib; их код в этот репозиторий не входит.

**Основа**

- Все функции Telegram для Android 12.10.6.
- Собственные имя, значок, первый экран, значок уведомлений.
- Вход только по ключам API сборщика; сервисы, привязанные к официальному приложению, отключены.
- При обновлении с 2.x старые данные аккаунтов удаляются: новая версия их прочитать не может. Провайдеры и ключи ассистента сохраняются.

**Оформление**

- Ползунки стекла: плотность, размытие под прозрачным и матовым стеклом, преломление, блик.
- Отклик кнопок: желе, стекло, обычный.
- Переключатели в стиле iOS, жирный шрифт системы.
- Панель вкладок без подписей, скрытие кнопки камеры для историй.

**Ассистент**

- Провайдеры с собственным ключом, два формата запросов, загрузка списка моделей.
- Разговор с оформлением ответов.
- Пункт «Ассистент» в меню сообщения и в меню чата.
- Согласие перед первой отправкой текста провайдеру.

**Для разработки**

- Отладочный демо-режим без аккаунта.

**Не вошло** (появилось в 3.1)

- Плагины.
- В ассистенте: несколько разговоров, картинки, распознавание речи.
