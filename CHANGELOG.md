# История изменений

## 3.2 — октябрь 2026

**Вид в духе iOS**

- У стрелки «Назад» в чате — число непрочитанных сообщений в других чатах; капсула растягивается под число.
- Заголовок чата занимает столько места, сколько нужно названию, и стоит по центру. На других экранах слишком длинный заголовок сначала уменьшается.
- Скрепка — в собственном стеклянном круге слева от поля ввода, кнопка записи и отправки — отдельно справа. Скрепка не исчезает, пока вы печатаете.
- Стекло под стрелкой, заголовком, меню и скрепкой поддаётся под пальцем вместе с кнопкой; выбранная вкладка «выпрыгивает».
- Профиль без своего цвета получает шапку в цвет аватара.
- На заставке при запуске — знак Ngram, а не самолётик Telegram.

**Лента** — новая вкладка

- Свежие посты всех ваших каналов одним списком по времени, с картинками и числом просмотров.
- Фильтры «Все», «Новые», «Отложенное»; пост можно отложить, переслать себе, убрать его канал из ленты.
- Пересказ ленты ассистентом.
- Настройки: каналы без звука и из архива, пересланные посты, скрытие по словам, короткие посты, сплошной список, список каналов.

**Настройки Ngram**

- В настройках Telegram — одна строка «Ngram»; за ней экран с плитками разделов.
- «Оформление» разбито на страницы: стекло, движение и элементы, экран чата и профили, главный экран, значок.
- Разделы переименованы, чтобы не совпадать с разделами Telegram: «Переписка», «Копия и отчёт», «Разбор чата», «Перевод ассистентом».
- Пункт «В Избранное» в меню сообщения выключен по умолчанию: у Telegram есть «Переслать».

**Плагины** — переработаны

- Собственный набор Ngram (пакет `ngram`): паспорт из комментариев, декораторы для команд, событий, пунктов меню и таймеров, строки настроек, хранилище, тексты на нескольких языках, обмен функциями между плагинами.
- Новые события: открытие и закрытие чата, открытие ссылки, выход приложения на экран, любое внутреннее уведомление приложения.
- Перед установкой Ngram читает файл и показывает, что умеет его код.
- Установка по ссылке, обновление по ссылке из паспорта, пакеты Python с pypi.org по запросу плагина.
- На странице плагина: число вызовов и среднее время, перезапуск с перечитыванием файла.
- Пункты плагинов в меню главного экрана. Пять примеров вместо трёх.
- Плагины exteraGram продолжают загружаться.

**Ассистент**

- Панель вместо списка: цитата, действия плитками, строка для своего вопроса, текущая модель.
- Новое над чатом: «О чём договорились», «Что ждут от меня», «Вопросы без ответа».

**Переписка**

- «Напомнить» в меню сообщения: сообщение придёт в «Избранное» в выбранное время.
- «Неотправленное» в меню главного экрана: все чаты с набранным и не отправленным текстом.

**Значки**

- Десять новых значков: Стекло, Терминал, 3310, Ретро 95, Синтвейв, brat, Deal With It, Нян, Stonks, Кот. Всего шестнадцать, все на одной странице.

**Под капотом**

- Профиль для предварительной компиляции (baseline profile): на свежеустановленном приложении часто используемый код компилируется заранее.
- Служебная уборка при запуске перенесена с главного потока.
- В вопросах о разрешениях приложение называет себя Ngram.

## 3.1 — октябрь 2026

**Плагины** — вернулись из Ngram 2.x, теперь на настоящих классах Telegram

- Расширения на Python 3.11 с именами SDK, как в exteraGram: команды, перехват отправки, хуки запросов и обновлений, пункты меню, собственные настройки.
- Установка из файла, из сообщения в чате и из трёх встроенных примеров; согласие перед установкой.
- Страховка: самоотключение плагина после 8 ошибок подряд, безопасный режим, журнал.

**Чаты** — новый раздел настроек

- Секунды во времени сообщений, точные числа вместо «12,3K», размер стикеров.
- Двойное нажатие на сообщение: реакция, ответ, изменить, скопировать, в Избранное, подробности или ничего.
- Вопрос перед отправкой стикера, GIF и перед звонком; «сначала прослушать» для голосовых.
- Отключаемый переход к следующему каналу потягиванием; скрытие клавиатуры при прокрутке.
- Меню сообщения: «В Избранное», «Повторить», «Копировать фото», «Сохранить стикер как картинку», «Подробности».
- Меню чата → Ngram: шаблоны с подстановками, переход к началу чата, статистика, экспорт переписки в текст, веб-страницу или JSON.
- «Сведения» в меню профиля.
- «Скрывать мой номер» и запрет снимков экрана.

**Оформление**

- Цветной оттенок стекла.
- Наборы стекла: пять готовых и свои.
- Шесть значков приложения Ngram вместо значков Telegram.
- Свой заголовок главного экрана; ряд историй можно убрать.

**Ассистент**

- Несколько разговоров: список, переименование, удаление.
- Картинки: что на фото, текст с фото, вопрос о фото.
- Расшифровка голосовых и видеосообщений через провайдера (модель для речи в настройках провайдера).
- В секретных чатах и чатах с запретом копирования ассистент не предлагается.

**Данные**

- Копия настроек Ngram в файл и восстановление из файла (без ключей API).
- Диагностика: отчёт и последний сбой.

**Прочее**

- Приложение стало больше примерно на 18 МБ: в него встроен Python.
- Номер сборки включает версию Ngram, поэтому каждая следующая версия ставится поверх предыдущей.
- Сборку можно подписать своим ключом: он задаётся в `local.properties` (см. [docs/building.md](docs/building.md)).

## 3.0 — октябрь 2026

Ngram переехал на исходный код Telegram для Android 12.10.6. Предыдущие версии (1.x–2.x) были отдельным приложением на TDLib; их код в этот репозиторий не входит.

**Основа**

- Все функции Telegram для Android 12.10.6.
- Собственные имя, значок, первый экран, значок уведомлений.
- Вход только по ключам API сборщика; сервисы, привязанные к официальному приложению, отключены.
- При обновлении с 2.x старые данные аккаунтов удаляются: новая версия их прочитать не может. Провайдеры и ключи ассистента сохраняются.

**Оформление**

- Ползунки стекла: плотность, размытие под прозрачным и матовым стеклом, преломление, блик.
- Отклик кнопок: желе, стекло, обычный.
- Переключатели в стиле iOS, жирный шрифт системы.
- Панель вкладок без подписей, скрытие кнопки камеры для историй.

**Ассистент**

- Провайдеры с собственным ключом, два формата запросов, загрузка списка моделей.
- Разговор с оформлением ответов.
- Пункт «Ассистент» в меню сообщения и в меню чата.
- Согласие перед первой отправкой текста провайдеру.

**Для разработки**

- Отладочный демо-режим без аккаунта.

**Не вошло** (появилось в 3.1)

- Плагины.
- В ассистенте: несколько разговоров, картинки, распознавание речи.
