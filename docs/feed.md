# Лента

Вкладка **Лента** на главном экране (между «Чатами» и «Контактами»)

Лента собирает свежие посты каналов, на которые вы подписаны, в один список по времени — как лента в соцсети, только из ваших каналов Telegram и без рекомендаций.

## Что на экране

| Элемент | Что делает |
| --- | --- |
| **Все / Новые / Отложенное** | Все посты; только непрочитанные; посты, которые вы отложили. |
| Пост | Канал и время, текст, картинка или кадр видео, число просмотров. Синяя точка — пост ещё не прочитан в канале. |
| Нажатие на пост | Открывает канал на этом посте. |
| Долгое нажатие | «Отложить», «Переслать себе», «Скопировать ссылку», «Убрать канал из ленты». |
| Значок перевода | Пересказ ленты ассистентом: 5–9 пунктов по свежим постам. Нужен настроенный [ассистент](assistant.md). |
| Круговая стрелка | Обновить. Лента сама обновляется, если её не открывали три минуты. |
| Шестерёнка | Настройки ленты. |

## Настройки

`Настройки → Ngram → Лента` или шестерёнка в ленте

| Настройка | Что делает |
| --- | --- |
| Лента на панели вкладок | Без вкладки лента открывается из меню главного экрана (три точки). |
| Каналы без звука | Показывать ли каналы, у которых вы отключили уведомления. |
| Каналы из архива | Показывать ли архивные каналы. |
| Пересланные посты | Показывать ли репосты из других каналов. |
| Скрывать посты со словами | Пост с любым из слов в ленту не попадает; в канале он остаётся. |
| Картинки и кадры видео | Загружаются по правилам автозагрузки Telegram. |
| Короткие посты | Четыре строки текста и невысокая картинка. |
| Сплошной список | Посты подряд, без промежутков между карточками. |
| Засчитывать просмотры | См. ниже. |
| Каналы в ленте | Отметка у каждого канала: снимите, чтобы убрать его из ленты. |

## Честность перед каналами

- **Просмотры засчитываются.** Пост, показанный в ленте, считается просмотренным — так же, как при открытии канала. Это можно выключить, но по умолчанию автор канала видит честное число.
- **Отметки о прочтении лента не трогает.** Канал остаётся непрочитанным, пока вы его не откроете.
- **Запреты уважаются.** Пост из канала с запретом пересылки нельзя переслать себе.
- **Отложенное хранится на устройстве**: до 200 постов, текстом, никуда не отправляется.

## Как это устроено

У Telegram нет запроса «посты всех моих каналов», поэтому лента делает то же, что делало бы приложение, открывая каналы по очереди:

1. Берёт до 60 каналов, самые недавно обновлявшиеся — первыми.
2. Запрашивает у каждого страницу истории (12 постов), по пять каналов одновременно.
3. Сливает страницы по времени. Альбом из нескольких картинок становится одним постом.
4. Не показывает пост раньше времени: пока у какого-то канала могут найтись посты новее, более старые придерживаются. Листаете вниз — подгружается следующая страница у тех каналов, которые «держат» ленту.
